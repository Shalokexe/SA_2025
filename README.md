# Summer Analytics 2025 - IIT Guwahati

Welcome to the official repository for **Summer Analytics 2025**, a free, 5-week online data science and machine learning training program organized by the Consulting & Analytics Club (C&A) at IIT Guwahati. This program is designed to launch your journey into data science with an industry-relevant curriculum covering Python programming, data manipulation, machine learning, and real-world analytics applications.

## Program Overview
- **Duration:** 5 weeks
- **Format:** Online
- **Organized by:** Consulting & Analytics Club, IIT Guwahati
- **Co-presented by:** Pathway
- **Course Focus:**
  - Python for Data Science (NumPy, Pandas)
  - Data Wrangling & Visualization (Matplotlib, Seaborn)
  - Machine Learning (supervised & unsupervised learning, decision trees, feature engineering, hyperparameter tuning)
  - Introduction to Neural Networks and Deep Learning
  - Real-time Data Streaming applications  

## Weekly Curriculum Highlights
- Week 1: Python basics, data analysis, and visualization
- Week 2: Handling missing values, intro to machine learning, linear and logistic regression
- Week 3: Model evaluation, regularization, unsupervised learning techniques
- Week 4: Advanced ML models like SVM, decision trees, boosting methods
- Week 5: Deep learning foundations, neural network implementation, anomaly detection
